# Inventory Management System

Full-stack web application for the Course Final Project.

## Technology
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP
- MySQL

## Setup using XAMPP
1. Copy this folder to `C:/xampp/htdocs/`.
2. Start Apache and MySQL.
3. Open phpMyAdmin.
4. Import `database.sql`.
5. Visit `http://localhost/inventory_management_system/`.
6. Login using:
   - Username: `admin`
   - Password: `admin123`

## Main Modules
- Login / Authentication
- Dashboard
- Product CRUD
- Category CRUD
- Supplier CRUD
- Stock status monitoring
